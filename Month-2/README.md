# Month 2: Network Services, Wireless and Security

Month 2 builds on the foundations from Month 1. You learn the services that make a network usable, how wireless networks work, and how to secure, monitor and troubleshoot a network.

**Duration:** 4 weeks, 2 classes per week (8 classes in total)

---

## Week 5: DHCP, DNS, TCP/UDP and NAT

[Open Week 5](Week-5_DHCP-DNS-TCP-UDP-and-NAT/)

This week covers the services that run on almost every network.

- **DHCP:** automatically giving IP addresses to devices
- **DNS:** turning names like google.com into IP addresses
- **TCP and UDP:** the two transport protocols, and when each one is used
- **NAT:** letting many private devices share one public IP address

**You will be able to:** explain how a device gets its IP address, how a website name is resolved, and how NAT works.

---

## Week 6: Wireless Networking

[Open Week 6](Week-6_Wireless-Networking/)

This week explains how devices connect without cables.

- **Wi-Fi standards:** the different wireless standards and their speeds
- **Access points and WLANs:** how wireless networks are built and named
- **Wireless security:** how encryption and authentication protect a Wi-Fi network
- **Wireless design basics:** channels, coverage and common problems

**You will be able to:** describe how a wireless network is built and choose a safe security setup.

---

## Week 7: Network Security Fundamentals, ACL and Firewall

[Open Week 7](Week-7_Network-Security-Fundamentals-ACL-and-Firewall/)

This week focuses on protecting the network.

- **Security basics:** common threats and how networks defend against them
- **ACL (Access Control Lists):** rules on a router or switch that allow or block traffic
- **Firewall:** a device that filters traffic between trusted and untrusted networks

**You will be able to:** write basic ACL rules and explain where a firewall fits in a network.

---

## Week 8: VPN, Monitoring and Troubleshooting

[Open Week 8](Week-8_VPN-Monitoring-and-Troubleshooting/)

The final week covers remote access and keeping the network healthy.

- **VPN:** secure connections over the internet for remote users and branch offices
- **Monitoring:** watching the network with tools and logs
- **Troubleshooting:** a step-by-step method to find and fix problems, using tools like ping and traceroute

**You will be able to:** explain how a VPN works and use a clear method to troubleshoot network problems.
