# Month 1: Networking Foundations

Month 1 builds the base of networking. You start with how networks communicate, then learn addressing, switching and routing. By the end of this month you can explain how data moves from one device to another and configure the basic building blocks of a network.

**Duration:** 4 weeks, 2 classes per week (8 classes in total)

---

## Week 1: Introduction to Networking, OSI, TCP/IP, Ethernet, MAC and ARP

[Open Week 1](Week-1_Introduction-to-Networking-OSI-TCP-IP-Ethernet-MAC-ARP/)

This week explains what a network is and how devices talk to each other.

- **OSI model:** the 7 layers and what each layer does
- **TCP/IP model:** the practical model the internet uses and how it maps to OSI
- **Ethernet:** how devices on a local network send frames
- **MAC address:** the physical address of a network card
- **ARP:** how a device finds the MAC address that belongs to an IP address

**You will be able to:** explain what happens at each layer when data is sent, and describe how ARP works.

---

## Week 2: IPv4, IPv6 and Subnetting

[Open Week 2](Week-2_IPv4-IPv6-and-Subnetting/)

This week covers IP addressing, which is the most important skill for any network engineer.

- **IPv4:** address structure, classes, public and private addresses
- **IPv6:** why it exists, address format and basic types
- **Subnet masks and CIDR:** how an address is split into network and host parts
- **Subnetting:** dividing one large network into smaller networks

**You will be able to:** calculate subnets, host ranges and broadcast addresses, and read an IPv6 address.

---

## Week 3: Switching, VLAN, Trunking and STP

[Open Week 3](Week-3_Switching-VLAN-Trunking-and-STP/)

This week focuses on how switches work inside a local network.

- **Switching:** how a switch learns MAC addresses and forwards frames
- **VLAN:** splitting one physical switch into separate logical networks
- **Trunking:** carrying several VLANs over a single link between switches
- **STP (Spanning Tree Protocol):** preventing loops when switches are connected in a ring

**You will be able to:** create VLANs, configure trunk links and explain how STP keeps the network loop-free.

---

## Week 4: Routing Fundamentals, Inter-VLAN Routing, OSPF and HSRP

[Open Week 4](Week-4_Routing-Fundamentals-Inter-VLAN-Routing-OSPF-and-HSRP/)

This week connects different networks together.

- **Routing fundamentals:** routing tables, static routes and dynamic routing
- **Inter-VLAN routing:** letting devices in different VLANs communicate
- **OSPF:** a dynamic routing protocol that finds the best path automatically
- **HSRP:** a backup gateway system that keeps the network running if a router fails

**You will be able to:** configure routing between networks and build a network with a backup gateway.
