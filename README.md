# Networking Fundamentals Course

A complete 8-week Codelivly Network Engineering program with recorded lecture videos and presentation slides. There are 2 classes per week, so 16 classes in total.

## Course Structure

### Month 1

| Week | Topic |
|------|-------|
| Week 1 | Introduction to Networking, OSI, TCP/IP, Ethernet, MAC and ARP |
| Week 2 | IPv4, IPv6 and Subnetting |
| Week 3 | Switching, VLAN, Trunking and STP |
| Week 4 | Routing Fundamentals, Inter-VLAN Routing, OSPF and HSRP |

### Month 2

| Week | Topic |
|------|-------|
| Week 5 | DHCP, DNS, TCP/UDP and NAT |
| Week 6 | Wireless Networking |
| Week 7 | Network Security Fundamentals, ACL and Firewall |
| Week 8 | VPN, Monitoring and Troubleshooting |

## How to use this repository

1. Open the Month folder.
2. Open the Week folder.
3. Open Day-1 or Day-2.
4. Each Day folder has the class video link and the slides.
